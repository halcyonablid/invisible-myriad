# Paradigm Panel Visual State Semantics

## 1. 作用

这是范式面板的视觉语义附录，不是主交互协议。

## 2. 必须表达清楚的状态

1. branch 颜色
2. mounted row 凸显
3. direct vs inherited 差异
4. copy 语义与 editor scope 区分
5. TOC 与 panel 的 mounted / inherited parity

## 3. 原则

1. 不做泛化美化，严格对齐原版 visual contract
2. 已展示节点的 direct / inherited 状态语义必须一致
3. panel row、editor scope、TOC 不能各说各话
