# 环境与依赖

建议使用满足全部 `plugin-inventory.json` 中 minAppVersion 要求的桌面版 Obsidian。Obsidian 本体未打包。本库保留当前插件程序，移动端及其他操作系统未认证。

|功能|前提|
|---|---|
|常规笔记、视图与数据编辑|Obsidian 桌面，社区插件启用|
|Ontology / Reference Graph 的高级离线布局|PATH 中 Node 18+；CP-SAT 还需 Windows x64 的 Python 3.12 与 `py` 启动器|
|布局依赖|已附 Node 包、WASM、OR-Tools 与 Python 依赖；不必全局 pip 安装，保留各自许可证|
|Pandoc 导出|另装 Pandoc 并在插件设置配置；Pandoc PDF 格式还可能要求 TeX 引擎|
|Better Export PDF|Obsidian 桌面的 Electron 打印环境|
|BRAT 更新、Excalidraw 在线字体/AI、远程嵌入|相应网络服务；AI 密钥需自己配置，本包没有密钥|
|样式调整|保留 Style Settings / Minimal Settings；未复制私人主题，自带基础主题可用|

在此目录运行 `py tools/check-environment.py` 只读检查外部程序。高级布局完整前提与限制见 `.obsidian/plugins/ontology-meta-hub/layout-engines/README.md`。依赖缺失不等于功能被删除；需要在接收机器安装对应前提后验收。
