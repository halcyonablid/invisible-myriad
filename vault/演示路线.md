# 十分钟走一遍

所有记录都是虚构样例，固定日期为 2026-10-05 至 2026-10-09；日课和周追踪请切换到该日/第41周。

1. **0–2 分钟，EVA Tree**：展开 ATOM@1，读“准备十分钟分享”，沿编号查看听众问题、材料、行动与回顾；ATOM@2 是独立观察话题。
2. **2–4 分钟，Keyword Index**：打开“材料”，进入两条不同话题的材料笔记，展示入口与编号的不同作用。
3. **4–6 分钟，SuperMemo Concept Display**：查看清空后的 Concept，以及保留结构的主体树和 Antinet 框架。四段十分钟计划仍可从命令面板打开 SuperMemo Plan。
4. **6–8 分钟，视图组**：Workspace 已放四份材料，Collection 放三项明确行动；GTD 放一个项目、一条收件箱启发和一条下一步。打开条目绑定笔记，看看问题如何落到具体文字。
5. **8–10 分钟，回顾**：Timeline 看排练周期；Mandala 日课切到10月5日、周追踪切到第41周。目标管理从 Mandala 命令打开。最后在日课写下一条自己的观察。

视图组保留十二项：项目执行总览、Workspace、GTD、Collection、时间框架、Timeline、下一步行动台、Ontology、每日 Note 回看、时间块记录、日课、周追踪。组内菜单由原插件生成；首次预热未完成时使用“修复视图组”。

## 继续体验

打开 `Examples/分享白板.canvas` 使用 Canvas；在命令面板搜索 Excalidraw 创建画板，搜索个人基金账本建立自己的虚构账例，搜索 SuperMemo Concept 查看概念界面。模板和每日笔记已配置，可在命令面板调用。

打开 `System/Mermaid/ATOM-List.md`，将它与 Mermaid 浮动图并排放置，再从列表选择 ATOM 笔记，体验列表与图的定位。该入口已做可移植路径迁移，真实图中点击与定位仍须按验收清单实机核对。

项目执行总览、下一步行动台和 Ontology 会按来源身份聚合证据。同名文字不等于已建立有效操作上下文；本例不伪造跨插件关联成功。要练习关联，用原生界面声明主键、设置周追踪并创建 EVA 关系，再核查跳回来源。时间框架和基金账本保留功能，以干净数据开始。


## Concept 清理修订

第三个首页标签为 SuperMemo Concept Display。Concept 使用本库专属文件保存，不再直接使用宿主共享的内容存储。

首次在原电脑打开本修订库时，只从宿主读取主体结构树与 Antinet 框架，保留节点名称、层级、顺序和生命周期，重新生成节点标识。Concept 正文、胶囊、义胶囊、页面、评论、草稿、关联和历史预留标识均不导入。原库与宿主数据不会被清除或改写。若另一台电脑没有原框架，初始结构为空。

后续保存位于插件目录的 showcase-concept-storage.json；初始化标记为 showcase-concept-initialized.json。重新打开会保留本库新增内容。请备份这两个文件；文件损坏、缺失或并发冲突时停止写入，不会自动恢复旧内容。共享新版程序时保留它们；对外重新打包前需单独审查，打包脚本拒绝带入这些初始化数据。

本次包内没有提取原电脑的框架。结构保留在首次同机打开时执行，原生界面验收尚待完成。
